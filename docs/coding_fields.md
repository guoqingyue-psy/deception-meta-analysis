# 探索期最小记录字段

版本：2026-10-20。此文件为AI按本次同步需求整理的字段建议，供继续阅读时使用；不是本人已确认的最终编码手册或预注册方案。允许后续调整研究问题、指标和调节变量。

## 每篇先记录什么

| 字段 | 最小记录要求 |
|---|---|
| 文献标识 | 稳定编号、题名、作者年份、DOI或可回查来源 |
| 研究类型与问题 | 实证、元分析、综述或方法学研究；作者想回答什么 |
| 样本与情境 | 被试特征、样本量、实验室或现实情境；元分析另记纳入范围和研究数的计数单位 |
| 任务与实验流程 | 被试获得什么信息、收到什么指令、完成什么任务；是否有欺骗动机、奖励或反制 |
| 比较条件 | 明确比较哪两类刺激、条件或人群；被试内还是被试间；元分析中的效应量单位是否与单次实验的对比相同 |
| 结果指标 | 指标名称、单位、计时起止或时间窗、变化方向；效应量另记定义、正负方向、是否经过何种校正 |
| 核心结果 | 结果、适用条件、区间或其他不确定性信息；按原文记录，缺项不猜 |
| 候选调节变量 | 变量名及实际取值或分组；区分被编码、被检验和发现显著调节 |
| 局限与解释边界 | 证据支持到哪里、不能推出什么；区分作者指出与本人/AI推论 |
| 出处与核对状态 | 章节、页码、表图或原卡单元格；记录核对状态和日期 |
| 个人疑问/启发（选填） | 有就记录；注明本人想法、作者观点或AI建议，尚未确认的研究空白保持为疑问 |

这些字段用于逐步记录，不要求初读时全部填满。元分析的总体效应不能直接当作新的原始研究效应再重复汇总；若后续开展新元分析，应按确定的方案回到原始研究提取并处理依赖关系。

## 阅读与核对分别记录

- 阅读状态沿用总览：待读、阅读中、已读。阅读状态不能代替核对状态。
- 核对状态可写：未核对、部分待核对、已本人核对。只有本人明确确认后，才将对应内容标为已本人核对，并记录出处和日期。
- 「AI代整，待本人核对」原样保留；来源没有明确标记时，不自行推断该内容完全出自本人或已经核验。
- 空白表示尚未填写；「待核实」表示仍需查原文；「未报告」仅在已检查原文、确认未提供时使用；「不适用」须说明原因。
- 未来日程、预估用时和候选研究问题分别保留为计划、估计和疑问，不改写成已完成或已证实。

## 指标比较的最低要求

| 指标或结果 | 比较前必须说明 |
|---|---|
| RT均值差/标准化差异 | 比较条件、计时区间、单位或标准化方式、正负方向；不直接换算个体识别准确率 |
| CIT检测分数及其标准化差异 | 分数如何由关键/无关项目得到；比较的是哪些人或哪些条件；是否使用模拟的不知情者分布 |
| AUC | 无区分能力的参照为0.5；与特定阈值下的正确率分别记录 |
| 个体分类表现 | 阈值与验证方式、样本组成；若有，分别记录敏感度、特异度和准确率 |
| 生理/ERP指标 | 各指标的定义、时间窗与方向；不能因同属CIT就默认测量同一加工过程或可直接合并 |

不同任务或指标是否能够合并，留到研究问题与比较条件明确后决定；当前不预设统一效应量或分析模型。

## 本次文件对应关系

- literature_index.csv保留文献总览A:I原有内容，另加核对状态、来源位置、同步日期。
- reading_notes.md保留第一篇已填写的核心记录、第二篇C15:C17以及明确的缺项与疑问。
- 新增的核对状态和本字段建议由AI依据现有卡片整理；没有将任何记录升级为「已本人核对」。
